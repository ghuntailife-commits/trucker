# Trucker dialer

The next generation of the George Truckers dialing system: a web app with one shared database for every agent.

- `src/rules/` follow-up rules and the Today ranking (pure functions, no database)
- `test/` automated tests for every rule (`npm test`)
- `docs/CHANGELOG.md` everything that changed from the v27 sheet, and why
- `docs/TEST-CHECKLIST.md` the rules checklist the tests cover

Status: stage 1 of 8 (rules + tests). See the plan doc for the stages.
